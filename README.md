# 30-Day C Programming Challenge

Welcome to my repository! This project contains my daily code submissions for the 30-day C programming summer assignment. 

## 📌 About This Repository
This repository serves as a personal log of my 30-day coding journey. Every day, I am tackling new programming problems, writing the logic in C, and committing the code here. The goal of this challenge is to build a strong foundation in C programming, logic building, and version control using Git.

## 📂 Folder Structure
All code is organized sequentially by day. Inside each day's folder, you will find the C source code files for those specific tasks.
